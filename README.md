# EU AI Act ontology

A proof-of-concept OWL ontology of the EU AI Act, developed for the King's College London research associate technical task.

## Status

Design discussion in progress. This repository does not yet contain an ontology or implementation. Each approach is developed on its own branch so its modelling choices can be compared.

## Task scope

The ontology should record the Act's AI system categories, prohibited practices, high-risk systems, core actors, and major obligations, with labels, short descriptions, and article references. The deliverables also include a documented AI-assisted workflow, 3–5 competency questions with example SPARQL queries, a demonstration that the ontology loads in Protégé and is consistent under a standard reasoner, and proposed preliminary evaluation metrics. The documentation note is limited to two pages; prompts, scripts, and intermediate artefacts should be retained for reproducibility.

## Development record

1. Created the repository. No legal provisions have been extracted or modelled yet.
2. Agreed to use OWL and to focus on recording the Act's categories and obligations for querying. The particular OWL 2 profile and description logic expressivity remain open until the intended queries and axioms are specified.
3. A separate branch will develop the initial record-and-query representation. No implementation has begun.

## Reproducing the current state

Clone the repository and read this README. There are no dependencies, build steps, or generated outputs at this stage. Commands and source versions will be added here when implementation begins.
